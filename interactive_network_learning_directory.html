ชุดเครื่องมือและแบบทดสอบ Subnetting สด

ทดลองคำนวณและทดสอบความเร็วการวิเคราะห์ IP / Subnet Block Size ได้ทันทีที่นี่

โจทย์คำนวณความเร็ว คะแนน: 0

กำหนด IP และ CIDR Prefix:

192.168.10.45 / 26

สูตรลัด Block Size Method (Cheat Sheet Reference)

  • 1. สูตรคำนวณ Host: $2^{\text{host bits}} - 2$ (หัก Network ID และ Broadcast)
  • 2. หา Block Size: $256 - \text{Subnet Mask in interesting octet}$
    ตัวอย่าง: /26 Mask = 255.255.255.192 → Block Size = 256 - 192 = 64
  • 3. นับช่วง Network: เริ่มจาก 0 เพิ่มทีละ 64 (0, 64, 128, 192...)
